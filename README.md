# optpaste-site

Site do [OptPaste](https://github.com/alirioguerra/OptPaste), feito com React + Vite.

```sh
npm install
npm run dev      # desenvolvimento
npm run build    # gera dist/ para publicar
```

Publicado na Vercel (preset Vite: `npm run build`, saída em `dist/`).

O botão de download busca a release mais recente do repositório OptPaste no GitHub
(incluindo betas) e aponta direto para o `.dmg`/`.zip` anexado, se houver.
